		Now we want to store relations:
	
		Cars have owners
		Owners have cars
		Onwers have data
		Cars have data

		How would we use NOSQL to store these piece of data and their relationships?

		if we have with license plate number 123456 we will store it as key="car_123456" with
		value like this:

			{
				"color": "red",
				"manufacturer": "Mazda",
				...
				owners="owner_014995815, owner_45645645"
			}

		if we have an owner with id 014995815 we will store key="owner_014995815" with a value
		like this:

			{
				"age":...,
				"birthday":...
				...

				cars_owned=""
			}
