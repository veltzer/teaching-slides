Here is a problem:

You have functions/methods calling functions/methods calling functions/methods ...
How to you pass a paramter from the high fuctions/methods to the low functions/methods?

Method 1 - arguments
pros:
- you can pass a differrent value on every invocation.
cons:
- ALL the functions down the chain have to be aware of the argument and pass it off
- this is run time intensive as all the arguments are really passed off.
- this means that you will have to change the signatures of all functions down the chain
EVERY TIME YOU NEED ANOTHER ARGUMENT.
- this means that your APIs are not very stable (they could be made more stable with named
arguments but still...)
- above a certain number of arguments (6? 7?) this is ridiculous.

Method 2 - object with parameters
pros:
- still can pass a different value on every invocation.
- only one (?) object passed so API is stable and not all functions down the chain
	need to be modified on every parameters addition/removal.
cons:
- need yet another object.
- the act of passing the object is still done at runtime (slows down).
