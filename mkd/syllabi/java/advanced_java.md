Course Description
This course Improve the capabilities of Java developers by drilling covering selected advanced topics from Multithreading applications, to advanced collections, Functional Programming, working with services, Design patterns and many more.


Course Duration
32 Academic Hours (4 Days)


Prerequisites
2 years experience with Java programming
