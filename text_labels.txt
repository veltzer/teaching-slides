Code block language labels used in this project
================================================

Standard languages (Prism-recognized syntax highlighting):
- bash — shell scripts
- python — Python code
- c — C code
- cpp — C++ code
- csharp — C# code
- rust — Rust code
- yaml — YAML configuration
- json — JSON data
- hcl — HashiCorp Configuration Language (Terraform)
- cmake — CMake scripts
- markdown — Markdown content
- scala — Scala code
- javascript — JavaScript code
- makefile — Makefiles
- java — Java code
- sql — SQL queries
- dockerfile — Dockerfiles
- ini — INI configuration files
- toml — TOML configuration
- html — HTML markup
- go — Go code
- xml — XML markup
- ruby — Ruby code
- typescript — TypeScript code
- gas — GNU Assembler
- dts — Device Tree Source
- nginx — Nginx configuration
- kotlin — Kotlin code
- php — PHP code
- lua — Lua code
- groovy — Groovy code
- css — CSS stylesheets
- jsx — JSX (React)
- graphql — GraphQL queries
- protobuf — Protocol Buffers
- diff — Diff/patch output
- http — HTTP requests/responses
- jinja — Jinja2 templates

Custom semantic labels (no syntax highlighting, for categorization):
- tree — directory/file tree structures (using indentation, pipes, etc.)
- diagram — ASCII art diagrams, flowcharts, architecture drawings, box diagrams
- config — configuration file contents (generic, when not ini/toml/yaml/etc.)
- output — program output, log output, data dumps
- console — shell sessions with $ prompts, interactive terminal output
- template — template files, commit message templates
- gitignore — .gitignore file contents
- cron — cron expressions, systemd timer/calendar expressions
- protocol — network protocol examples
- misc — any text which doesn't comply with the previous definitions

Rare/one-off labels:
- esql — Elasticsearch query DSL
- asm — generic assembly
- arm — ARM assembly
- nasm — NASM assembly
- mips — MIPS assembly
- riscv — RISC-V assembly
- ld — linker scripts
- gdb — GDB commands
- promql — PromQL queries
- cython — Cython code
- cuda — CUDA code
- redis — Redis commands
- rego — Rego policy language
- vim — Vim script
- apache — Apache configuration
- properties — Java properties files
- conf — generic config files
- jsonc — JSON with comments
- jsonl — JSON Lines
- asl — ACPI Source Language
- wat — WebAssembly Text format
- terraform — Terraform (prefer hcl)
- gitattributes — .gitattributes files
- cfg — generic config files
