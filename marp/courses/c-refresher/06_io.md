# C Input and Output Refresher

---

## Standard I/O in C

- C provides standard input/output operations through `<stdio.h>`
- Three standard streams:
  - `stdin`: Standard input (keyboard by default)
  - `stdout`: Standard output (console by default)
  - `stderr`: Standard error (console by default)

---

## Basic Output: printf()

- `printf()` is used for formatted output
- Syntax: `printf("format string", arg1, arg2, ...);`

```c
int age = 30;
float height = 1.75;
printf("Age: %d, Height: %.2f meters\n", age, height);
// Output: Age: 30, Height: 1.75 meters
```

---

## Common Format Specifiers

- `%d`: Integer
- `%f`: Float
- `%c`: Character
- `%s`: String
- `%x`: Hexadecimal
- `%p`: Pointer

```c
printf("Hex: %x, Pointer: %p\n", 255, &age);
```

---

## Basic Input: scanf()

- `scanf()` is used for formatted input
- Syntax: `scanf("format string", &var1, &var2, ...);`

```c
int num;
char str[50];
printf("Enter a number and a word: ");
scanf("%d %s", &num, str);
printf("You entered: %d and %s\n", num, str);
```

---

## Character I/O: getchar() and putchar()

- `getchar()`: Reads a single character from stdin
- `putchar()`: Writes a single character to stdout

```c
int ch;
printf("Enter a character: ");
ch = getchar();
printf("You entered: ");
putchar(ch);
putchar('\n');
```

---

## String I/O: gets() and puts()

- `gets()`: Reads a line from stdin (deprecated due to security issues)
- `puts()`: Writes a string to stdout, appending a newline

```c
char str[100];
printf("Enter a string: ");
fgets(str, sizeof(str), stdin);  // safer alternative to gets()
puts("You entered:");
puts(str);
```

---

## File I/O: Basic Concepts

- File operations involve:
  1. Opening a file
  2. Reading from or writing to the file
  3. Closing the file
- File operations use `FILE` pointers

---

## Opening and Closing Files

- `fopen()`: Opens a file
- `fclose()`: Closes a file

```c
FILE *file = fopen("example.txt", "r");
if (file == NULL) {
    perror("Error opening file");
    return 1;
}
// Perform file operations here
fclose(file);
```

---

## Reading from Files

- `fscanf()`: Formatted input from a file
- `fgets()`: Reads a line from a file

```c
FILE *file = fopen("data.txt", "r");
int num;
char str[100];

fscanf(file, "%d", &num);
fgets(str, sizeof(str), file);

fclose(file);
```

---

## Writing to Files

- `fprintf()`: Formatted output to a file
- `fputs()`: Writes a string to a file

```c
FILE *file = fopen("output.txt", "w");
int num = 42;
char *str = "Hello, File I/O!";

fprintf(file, "Number: %d\n", num);
fputs(str, file);

fclose(file);
```

---

## Error Handling in I/O

- Always check return values of I/O functions
- Use `perror()` or `strerror()` for error messages

```c
if (ferror(file)) {
    perror("File error");
}

if (feof(file)) {
    puts("End of file reached");
}
```

---

## Summary

- `printf()` and `scanf()` for formatted console I/O
- `getchar()`, `putchar()`, `gets()`, and `puts()` for character and string I/O
- File I/O involves opening, reading/writing, and closing files
- Always handle errors and close files when done
- Use appropriate functions based on the type of I/O needed
