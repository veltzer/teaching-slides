# Chapter 5: Writing Your First Assembly Program

---

## "Hello, World!" in Assembly

Let's create a simple program that prints "Hello, World!" to the console.

```gas
.section .data
    message: .asciz "Hello, World!\n"

.section .text
.globl _start

_start:
    # Write the message to stdout
    movl $4, %eax        # sys_write system call
    movl $1, %ebx        # File descriptor 1 is stdout
    movl $message, %ecx  # Address of the message
    movl $14, %edx       # Length of the message
    int $0x80

    # Exit the program
    movl $1, %eax        # sys_exit system call
    movl $0, %ebx        # Exit status 0
    int $0x80
```

---

## Breaking Down the Program

1. `.section .data`: Defines the data section
2. `message:`: Label for our string
3. `.asciz "Hello, World!\n"`: Null-terminated string
4. `.section .text`: Begins the code section
5. `.globl _start`: Makes _start symbol global
6. `_start:`: Entry point of our program

---

## System Calls

Our program uses two system calls:
1. `sys_write` (4): Write to a file descriptor
2. `sys_exit` (1): Exit the program

System call numbers are placed in `%eax`.

Arguments are passed in registers:
- `%ebx`: First argument
- `%ecx`: Second argument
- `%edx`: Third argument
