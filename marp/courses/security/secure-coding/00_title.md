## What This Course Covers

- Supply chain security — dependencies, `SBOM`, signing, separation of duties
- Designing secure protocols with hardware support
- Encryption fundamentals and the pitfalls of getting it wrong
- `OWASP` and `NIST` — turning standards into code review checklists
- `CI/CD` security — secrets, scanning, artifact provenance
- Secure boot — the chain of trust from power-on
- Secure elements — `TPM`, `HSM`, enclaves, `TEE`
- Secure `AI` development — poisoning, adversarial attacks, `NIST` SP 800-218A

---

## How To Read This Course

- This is a **review course** — one day, eight topics, breadth over depth
- Each chapter could be a course on its own; here we map the terrain
- The goal: know what exists, what the risks are, where to dig deeper
- Examples come from `Linux`, C, `C++`, and `Python`
- Treat the standards references (`NIST`, `OWASP`) as your follow-up reading list

---

## Prerequisites And Audience

- Working knowledge of at least one of: C, `C++`, or `Python`
- Basic familiarity with `Linux`
- General understanding of software development workflows

Built for:

- Embedded and systems developers working in C / `C++`
- `Python` backend and infrastructure developers
- `DevOps` and `CI/CD` engineers
- Security engineers and architects
- Anyone working with hardware security and secure boot
