## Introduction to vi

Why learn vi?
- Present on all UNIX systems
- Fast and efficient
- No need for mouse
- Powerful features

---

## Starting vi

Basic commands:

```bash
# Open file
vi filename.txt

# Open multiple files
vi file1.txt file2.txt

# Open at specific line
vi +10 filename.txt

# Open at pattern
vi +/pattern filename.txt

# Open in read-only mode
view filename.txt
```

## Basic Navigation

Character movement:
```vim
h - left
j - down
k - up
l - right
```
Word movement:
```vim
w - next word
b - previous word
e - end of word
```

---

## Insert Mode Commands

Entering insert mode:

```vim
i - insert before cursor
a - append after cursor
I - insert at line start
A - append at line end
o - open line below
O - open line above
```

Example sequence:

```vim
i    # Enter insert mode
type your text
<Esc>  # Return to normal mode
```

## Moving Around

Line navigation:

```vim
0     - start of line
$     - end of line
^     - first non-blank
G     - last line
1G    - first line
nG    - line n
```

Screen navigation:

```vim
ctrl-f - page forward
ctrl-b - page backward
ctrl-u - half page up
ctrl-d - half page down
H     - top of screen
M     - middle of screen
L     - bottom of screen
```

## Command Mode Operations

Common commands:
```vim
:w        - save file
:q        - quit
:q!       - quit without saving
:wq       - save and quit
:set nu   - show line numbers
:help     - get help
```

## Search and Replace

Search:

```vim
/pattern     - search forward
?pattern     - search backward
n            - next match
N            - previous match
```

Replace:

```vim
:s/old/new         - replace first on line
:s/old/new/g       - replace all on line
:%s/old/new/g      - replace all in file
:%s/old/new/gc     - replace with confirm
```

## Copy, Cut, and Paste

Operations:
```vim

dd    - delete line
```

## Text Objects and Motions

Word operations:

```vim
dw    - delete word
cw    - change word
yw    - yank word
```

Sentence/Paragraph:

```vim
das   - delete a sentence
dap   - delete a paragraph
cis   - change inside sentence
```

Brackets/Quotes:

```vim
di"   - delete inside quotes
ci(   - change inside parentheses
yi{   - yank inside braces
```

## Advanced Features

Marks:

```vim
ma     - set mark 'a'
'a     - jump to mark 'a'
```

Macros:

```vim
qa     - record macro 'a'
q      - stop recording
@a     - play macro 'a'
```

Registers:

```vim
"ay    - yank to register 'a'
"ap    - paste from register 'a'
```

## Practical Examples

1. Edit Configuration File:

```vim
vi /etc/config.conf
i        # enter insert mode
<edit>   # make changes
<Esc>    # return to normal mode
:wq      # save and quit
```

1. Search and Replace:

```vim
:%s/oldconfig/newconfig/g
```

1. Copy Multiple Lines:

```vim
10G     # go to line 10
5yy     # yank 5 lines
p       # paste them
```
