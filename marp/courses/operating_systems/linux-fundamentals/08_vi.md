## Starting vi

Basic commands:

```bash
# Open file
vi filename.txt

# Open multiple files
vi file1.txt file2.txt

# Open at specific line
vi +10 filename.txt

# Open at pattern
vi +/pattern filename.txt

# Open in read-only mode
view filename.txt
```

## Insert Mode Commands

Entering insert mode:

```vim
i - insert before cursor
a - append after cursor
I - insert at line start
A - append at line end
o - open line below
O - open line above
```

Example sequence:

```vim
i    # Enter insert mode
type your text
<Esc>  # Return to normal mode
```

Line navigation:

```vim
0     - start of line
```

Screen navigation:


## Search and Replace

Search:

```vim
/pattern     - search forward
?pattern     - search backward
n            - next match
N            - previous match
```

Replace:

```vim
:s/old/new         - replace first on line
:s/old/new/g       - replace all on line
:%s/old/new/g      - replace all in file
:%s/old/new/gc     - replace with confirm
```

## Advanced Features

Marks:

```vim
ma     - set mark 'a'
'a     - jump to mark 'a'
```

Macros:

```vim
qa     - record macro 'a'
q      - stop recording
@a     - play macro 'a'
```

Registers:

```vim
"ay    - yank to register 'a'
"ap    - paste from register 'a'
```

## Practical Examples

1. Edit Configuration File:

```vim
vi /etc/config.conf
i        # enter insert mode
<edit>   # make changes
<Esc>    # return to normal mode
:wq      # save and quit
```

1. Search and Replace:

```vim
:%s/oldconfig/newconfig/g
```

1. Copy Multiple Lines:

```vim
10G     # go to line 10
5yy     # yank 5 lines
p       # paste them
```
