The course is intended for developers who want to get familiar with the
MongoDB database system. It is suitable both to developers with DB exprience
and without.

Introduction to NoSQL architecture with MongoDB

- What is MongoDB?

- Installation and configuration.

- MongoDB advantages.

- MongoDB data modeling.

- MongoDB tools, collection and documents.

CRUD and the MongoDB shell

- Introduction to CRUD.

- Introduction to the MongoDB API.

- Creating a database, collection and documents.

Data Modeling and Schema design

- MongoDB database references.

- Model Tree structures.

- MongoDB analysis queries.

- MongoDB atomic operations.

- MongoDB Map/Reduce.

- MongoDB Text search.

- MongoDB regular expressions.

- MongoDB Capped Collections.

MongoDB Administration

- MongoDB Deployment and Cluster Management.

- MongoDB Grid FS.

- Trident Spout.

- Working with Replica Sets.

- MongoDB Sharding.
